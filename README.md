# Golden Transfers API

## Decisões Arquiteturais

Sistema de agendamento de transferências financeiras desenvolvido com arquitetura MVC, separando responsabilidades em camadas de Controller, Service e Repository.

---

## Tecnologias Utilizadas

- Java 11
- Spring Boot
- Spring Data JPA
- H2 Database (banco em memória)
- Lombok
- Springdoc OpenAPI (Swagger)
- Maven
